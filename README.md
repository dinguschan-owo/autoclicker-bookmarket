# dinguschan's autoclicker bookmarklet

i got tired of subscription based autoclicker chrome extensions (are you out of your mind who charges for an autoclicker) and ones that just dont work, and apparently nobodys written an autoclicker bookmarklet since literally 2016. anyways heres a demo video

https://github.com/user-attachments/assets/eff969d3-2e87-4acd-a3e7-a6e9914335e7

## features

* click coordinates or automatically target full elements
* choose left, right, and double clicks
* fixed or randomized delay timing between a range (in ms)
* set specific click amounts or run forever
* add multiple targets at once
* drag the panels anywhere on screen (config menu and click counter)
* visual feedback

## how to use

1. create a new bookmark in your browser
2. set the name to Autoclicker or whatever you please
3. copy the code block below or in autoclicker.js and paste it into the URL or location field:
4. ur done, click on your new bookmark on your desired website to open the interface and use it
